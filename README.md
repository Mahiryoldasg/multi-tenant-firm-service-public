# Multi-Tenant Firma & Çalışan Yönetim Servisi

> Taslak — kurulum, seed bilgileri, örnek istekler ve test komutları build-plan'daki 14. maddede tamamlanacak.

## Gereksinimler

- Node.js 22 veya 24 LTS (en az 20.19)
- npm (Node.js ile gelir)

## Çalıştırma

```bash
npm install
npm start
```

Servis varsayılan olarak `http://localhost:4000` adresinde açılır.

## Testler

```bash
npm test
```
